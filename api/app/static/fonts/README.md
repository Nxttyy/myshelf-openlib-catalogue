Full TrueType versions of the app's fonts, for drawing link-preview cards
(app/services/og_card.py). Pillow needs .ttf, and the web app's .woff2 files
are split into Latin subsets.

- InterTight.ttf: Inter Tight (variable weight), SIL Open Font License 1.1
- JetBrainsMono.ttf: JetBrains Mono (variable weight), SIL Open Font License 1.1

Both from https://github.com/google/fonts (ofl/intertight, ofl/jetbrainsmono).
